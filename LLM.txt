# Umwelten (`LLM.txt`)

Umwelten provides multi-model evaluation (`EvalSuite`, `PairwiseRanker`, `Jev`), cross-harness session sensemaking (`@umwelten/sessions`, `@umwelten/pi`), host-agnostic `DurableHabitat` / `HabitatHost` orchestration (`@umwelten/habitat`), OAuth 2.1 `mcp-serve` (`@umwelten/protocols`), and the `Mycel` token Exchange (`@umwelten/mycel`, `@umwelten/supplier`) on top of `@earendil-works/pi-ai` and `@earendil-works/pi-durable`.

## Entry Points

- Pi CLI extension: `pi install ./packages/pi` (`umwelten_session_search`, `umwelten_promote_knowledge`, `/umwelten-explorations`)
- Evaluations: `import { EvalSuite, PairwiseRanker } from "@umwelten/evaluation"`
- Durable Habitats: `import { DurableHabitat, HabitatHost } from "@umwelten/habitat"`
- Session Sensemaking: `import { projectSessions, searchSessions, PromotionRouter } from "@umwelten/sessions"`
- OAuth MCP Server / Client: `import { createMcpServer, RemoteMcpClient } from "@umwelten/protocols"`
- Specifications & Verdicts: `docs/INDEX.md` (`pnpm run specs:check`)

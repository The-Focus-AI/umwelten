02 Connect your hardware

Manage your own
private cloud.

Run your own Mycel Exchange to manage a private fleet of model servers for your team. Choose which machines join and give your apps one API to use them. Run a model server on your machine or GPU server, register with the Exchange operator, and connect the Mycel supplier agent. Your models can serve requests while connected and stop receiving new requests when you disconnect. Reconnect to make them available again—apps keep using the same API.

04 How it works

Send a request.
Get a response.

Your app sends an OpenAI-compatible request. Mycel selects an available provider, returns the response, and records cost and usage.

  1. 01 · Request

    Your application

    POST /v1/chat/completions

    Sends a standard request using its Mycel API key and optional end-user identifier.

  2. 02 · Route

    Mycel Exchange

    capability + price + availability

    Matches the request against live offers and selects an eligible supplier.

  3. 03 · Response

    Selected model

    stream + usage record

    Streams tokens back through the same connection while Mycel records cost and usage.

05 For developers

Use your existing API.

Point your OpenAI-compatible requests at Mycel with your Mycel API key. Mycel handles routing and tracks cost and usage by app. Add an optional end-user ID to track usage by user.

  • OpenAI-compatible chat completions
  • Streaming and tool calling on supported models
  • Cost and usage tracking by app and user
request.ts 
const response = await fetch(
  "https://mycel.thefocus.ai/v1/chat/completions",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${MYCEL_API_KEY}`,
      "X-Mycel-End-User": user.id,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "deepseek/deepseek-v4-pro",
      messages
    })
  }
);

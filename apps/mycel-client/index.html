03 One request path

Your app calls Mycel.
Mycel handles the route.

Use the OpenAI API shape you already know. The Exchange selects an available supplier, streams its response, and records the usage.

  1. 01 · Request

    Your application

    POST /v1/chat/completions

    Sends a standard request using its Mycel API key and optional end-user identifier.

  2. 02 · Route

    Mycel Exchange

    capability + price + availability

    Matches the request against live offers and selects an eligible supplier.

  3. 03 · Response

    Selected model

    stream + usage record

    Streams tokens back through the same connection while Mycel records cost and usage.

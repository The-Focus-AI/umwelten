High-Level Architecture 02 / 12

Four Layers, Split Cleanly Across a Trusted Client Perimeter

Rethinking GaiaHost as a Client Environment: LLM + HTTP proxying, credentials, and wire-level audit live on the perimeter — never inside the agent runtime.

Two Planes, Zero Shared Secrets

The Perimeter Gateway holds keys, routes LLM/HTTP traffic, and logs traces; Habitat Runtime has no direct internet and zero upstream credentials.

Correlated Wire Audit

Every inbound A2A request mints one trace_id carried across Mycel LLM completions and QuickBooks/MCP egress calls.

Testable Offline First

Swap real providers for fauxProvider + mock upstreams locally (`examples/client-env/`) to test ACLs, redaction, and traces in milliseconds.

Runtime Foundation 03 / 12

Why DurableHabitat Beats Stateless Agent Scripts

Built directly on @earendil-works/pi-durable's transactional Harness and Node 24's built-in node:sqlite.

What Usually Breaks in Production

Typical Ephemeral Agent Wrapper

  • In-memory chat arrays lost on deploy or process crash.
  • Unbounded workspace file access when tools are enabled.
  • No safe way to branch from Turn 7 and test a prompt fix.
  • Cron jobs live in external scripts disconnected from session context.
  • Single global conversation leaks across callers or channels.
What DurableHabitat Gives Us

Transactional Habitat Store (habitat.sqlite)

  • Crash-safe resume: Commit turns atomically; harness.resume() recovers cleanly across restarts.
  • Zero-copy fork(entryId): Test fixes against real client state without mutating history.
  • Scoped execution: Omit ExecutionEnv (API-only) or enforce Owned R/W vs. Mounted R/O roots.
  • Armed sleep/wake: Durable HabitatCronTask stays scheduled even when idle Harnesses evict after 10m.

Step 01 · Hybrid Credential & Audit Proxy 05 / 12

Hybrid Proxy: Named Egress Routes + Correlated LLM Tracing

The Habitat holds zero QuickBooks OAuth tokens or LLM keys — every request crosses the Perimeter carrying x-trace-id.

1. Hybrid Egress Control

Named /egress/quickbooks & /egress/mcp routes enforce GET-only ACLs with zero TLS CA setup; optional CA forward proxy covers shell tools.

2. Wire-Level Traceability

Even if the agent stays silent, the proxy records every URL queried, method blocked (403), secret scrubbed, and micro-dollar spent.

3. ui:// Keeps Context Slim

Large 200-row aging schedules travel in _uiResources for the human while the LLM receives a 20-token summary.

Step 03 · Domain Ontology 07 / 12

Crystallize Tribal Accounting Knowledge into a Mounted Ontology

Raw QuickBooks tables do not know how the client defines ARR, COGS, or entity rollups. Version that meaning in Git.

"The model is interchangeable. The versioned client ontology and deterministic checks running alongside durable state are the real asset."

Mounted Read-Only Guard

The Habitat can always read updated rules from /ontology, but write/edit calls are rejected so runtime chats never silently corrupt client policy.

Automatic Drift Detection

TurnAnnotationProbe inspects every completed turn and flags new unmapped GL codes or split invoices in ConversationAnnotationsDoc for human review.

Step 04 · Spec & Verification Gate 08 / 12

Graduate Prototype Sessions via spec-extract & verify-deploy

Turn conversation discoveries and SME quirks into verifiable contracts before pushing a container to GCP.

1 · Extract Intent & Rules

spec-extract

Distills code diff + conversation transcript into modular packs:

  • docs/specs/agent/quickbooks-ops.md
  • [zero-secret-habitat-runtime] invariant
  • [perimeter-correlated-audit-trace]
  • docs/decisions.jsonl (D-1..N why-log)
2 · Freeze Edge Cases

EvalSuite + Matrix

Turns gnarly client scenarios into repeatable regression checks:

  • Accrual vs. cash cutoff test tasks
  • Pass-through GL exclusion accuracy
  • Benchmark fable vs. hydrogen vs. local qwen4
  • Zero-cost offline fauxProvider contract gate
3 · Gate Release

verify-deploy

No green verdict from prose — proves every invariant with live & sandbox checks:

  • Mode 1: read-only SQLite + trace ledger audit
  • Mode 2: 403 egress block + secret scrub drill
  • Writes immutable docs/runs/<ts>_<sha>/verdicts.jsonl

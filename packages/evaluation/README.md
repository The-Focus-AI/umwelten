# `@umwelten/evaluation`

Multi-model benchmarking (`EvalSuite`), head-to-head Elo tournaments (`PairwiseRanker`), calibrated probability judgments (`Jev` / Brier / ECE), and multi-suite scorecards (`combine` + `Reporter`) running directly over `@earendil-works/pi-ai` (`models.stream()`).

See [`examples/evals/`](../../examples/evals/), [`examples/jev/`](../../examples/jev/), and [`examples/model-showdown/`](../../examples/model-showdown/).
